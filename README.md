# floofie.org source code

code for https://floofie.org


## Installation

For Debian based systems, follow [this tutorial](https://jekyllrb.com/docs/installation/ubuntu/).

Then run:

```bash
  git clone https://github.com/MsFloofie/Floofie-Site.git
  cd Floofie-Site
  bundle install
  jekyll build -d $(mktemp -d)
```
